개인정보처리방침

시행일: 2026년 5월 1일 / 최종 개정일: 2026년 9월 9일

한국에가면(이하 "앱")은 한국 방문 시 필요한 항목을 체크리스트로 정리하고, 나만의 여행 영수증을 만들어주는 서비스입니다. 개발자 황지원(이하 "개발자")은 이용자의 개인정보를 중요시하며, 개인정보보호법, 정보통신망법 및 관련 법령을 준수합니다.

1. 수집하는 개인정보

본 앱은 회원가입 없이 이용 가능합니다.

1.1 이용자가 직접 입력하는 정보 (기기 내 저장)

체크리스트 선택, 여행 일정, 메모, 가격 등은 기기 내 로컬 저장소(localStorage)에만 저장되며 외부 서버로 전송되지 않습니다.

1.2 자동 수집 정보

  • Firebase Analytics 이벤트 - 앱 실행, 영수증 생성, 항목 체크, 언어 변경 등 익명 이벤트 로그 (app_instance_id, 기기 모델, OS 버전 포함)
  • 수집 시점 - Firebase Analytics 이벤트는 앱 설정의 "익명 사용 통계"에 동의한 경우에만 수집됩니다 (기본값 꺼짐). 같은 설정에서 언제든 끄면 즉시 수집이 중단됩니다.
  • Firebase Crashlytics - 앱 크래시 발생 시 스택 트레이스, 기기 상태, OS 버전
  • 기기 정보 - 기기 모델, OS 버전, 앱 버전 (서비스 안정성)

2. 개인정보 이용 목적

  • 앱 기능 제공: 체크리스트 저장, 영수증 생성, 일정 관리, 다국어 지원
  • 서비스 개선: Firebase Analytics로 이용 패턴 분석, Crashlytics로 안정성 모니터링

3. 개인정보 보유/이용 기간

  • 기기 내 로컬 데이터: 이용자가 앱을 삭제할 때까지 또는 앱 내에서 직접 삭제할 때까지
  • Firebase Analytics 이벤트 로그: Google 기본 정책에 따라 최대 14개월 보관 후 자동 삭제
  • Crashlytics 크래시 리포트: 90일 보관 후 자동 삭제

4. 국외이전

본 앱은 다음의 서비스를 이용하며, 이 과정에서 일부 정보가 대한민국 외 지역으로 이전될 수 있습니다.

  • Google Firebase Analytics / Crashlytics (미국) - 앱 분석/안정성 모니터링 목적. 이벤트 로그, 크래시 리포트 (영구 저장 아님, 상기 보유 기간 내). 개인정보처리방침: https://policies.google.com/privacy
  • Supabase (미국) - 앱 카테고리/항목 데이터 제공. 이용자 개인정보는 전송되지 않음
  • ExchangeRate API (open.er-api.com) (미국) - 통화 환산용 실시간 환율 조회. 요청 시 이용자 개인정보는 전송되지 않으며 환율 데이터만 수신

이용자는 개인정보 국외이전을 거부할 권리가 있으며, 거부 시 앱의 일부 기능(분석)이 제한될 수 있습니다.

5. 제3자 제공

이용자의 개인정보를 외부에 제공하지 않습니다. 단, 다음은 예외입니다:

  • 법령에 의거하여 수사기관이 적법한 절차로 요구하는 경우

6. 이용자의 권리

  • 열람/정정/삭제 요청 - 본 앱은 서버 측 이용자 데이터를 보관하지 않아 별도 열람 대상이 없으나, 분석 데이터 삭제 요청은 아래 이메일로 문의
  • 데이터 삭제 - 앱 삭제 시 기기에 저장된 모든 데이터가 영구 삭제됨
  • Firebase 데이터 삭제 요청 - 아래 이메일로 요청 시 Google에 삭제 요청 전달

7. 처리 위탁

앱 운영을 위해 일부 개인정보 처리를 아래 외부 서비스에 위탁합니다. 위탁 업체는 각자의 개인정보처리방침을 따릅니다.

  • Google Firebase Analytics / Crashlytics (Google LLC, 미국) - 이용 패턴 분석, 크래시 리포트. 정책
  • Supabase (Supabase Inc., 미국) - 앱 카테고리/항목 데이터 제공 (이용자 개인정보 전송 X)

8. 개인정보 안전성 확보 조치

개인정보보호법 제29조에 따라 다음과 같은 기술적/관리적 조치를 취합니다.

  • 외부 통신 구간 HTTPS 암호화
  • Supabase RLS(Row Level Security) 기반 접근 제어
  • 클라이언트 데이터는 기기 내 localStorage 격리 저장 (OS 샌드박스 보호)
  • 개인정보 접근 권한은 개인정보 보호책임자로 한정

9. 개인정보 보호책임자

  • 성명: 황지원 (개발자 겸 개인정보 보호책임자)
  • 이메일: dev.jiwonnie@gmail.com
  • 처리 기한: 요청 접수일로부터 지체 없이 처리 (최대 30일)

10. 개인정보처리방침 변경

본 방침이 변경될 경우 앱 내 공지 또는 본 페이지를 통해 시행일 최소 7일 전 안내합니다. 중대한 변경(신규 데이터 수집, 제3자 제공 확대 등)은 최소 30일 전 공지합니다.

Privacy Policy

Effective: May 1, 2026 / Last updated: September 9, 2026

Korea Receipt ("App") is a travel checklist app that helps users organize things to do when visiting Korea and generates a personalized travel receipt. Developer Jiwon Hwang ("Developer") values user privacy and complies with applicable privacy laws (Korea PIPA, GDPR principles where applicable).

1. Information We Collect

This app can be used without registration.

1.1 User-entered data (stored on device only)

Checklist selections, travel dates, memos, and prices are stored only in local storage on the device and are never transmitted to external servers.

1.2 Automatically collected data

  • Firebase Analytics events - Anonymous event logs (app open, receipt generated, item checked, language changed) including app_instance_id, device model, OS version
  • When collected - Firebase Analytics events are collected only if you opt in to "Anonymous usage statistics" in the app settings (off by default). Turning it off in the same settings stops collection immediately.
  • Firebase Crashlytics - Stack traces, device state, and OS version collected on crash
  • Device information - Model, OS version, app version (for stability)

2. Purpose of Collection

  • App functionality: checklist storage, receipt generation, schedule management, multi-language support
  • Service improvement: usage analysis via Firebase Analytics, stability monitoring via Crashlytics

3. Data Retention

  • Local device data: until the user deletes the app or clears it in-app
  • Firebase Analytics event logs: up to 14 months per Google's default policy
  • Crashlytics crash reports: 90 days

4. International Data Transfer

This app uses the following services, which may transfer data outside Korea:

  • Google Firebase Analytics / Crashlytics (United States) - For analytics and stability monitoring. Transfers event logs and crash reports. Retained within the periods above. Privacy policy: https://policies.google.com/privacy
  • Supabase (United States) - Provides app category/item data only. No user personal data is transferred.

You may decline international data transfer; doing so may limit analytics features but will not affect core app functionality.

5. Third-Party Sharing

We do not share personal information with third parties, except:

  • When required by law through proper legal procedures

6. Your Rights

  • Access / correction / deletion - We don't store user data on our servers; contact us for Firebase data deletion requests
  • Delete data - Uninstalling the app permanently removes all locally stored data
  • Firebase data deletion - Email us; we will forward the request to Google
  • California residents (CCPA/CPRA) - We do not sell or share your personal information for advertising purposes

7. Processing by Third-Party Processors

We rely on the following processors to operate the App. They follow their own privacy policies.

  • Google Firebase Analytics / Crashlytics (Google LLC, US) - Analytics, crash reporting. Policy
  • Supabase (Supabase Inc., US) - App category/item data (no user personal data transferred)

8. Security Measures

  • HTTPS encryption for all external communications
  • Supabase RLS (Row Level Security) for access control
  • Client data isolated in device-local localStorage (OS sandbox)
  • Personal data access limited to the Data Protection Officer

9. Data Protection Officer (DPO)

  • Name: Jiwon Hwang (Developer and Data Protection Officer)
  • Email: dev.jiwonnie@gmail.com
  • Response time: processed without delay, within 30 days at most

10. Changes to This Policy

Any changes will be announced in-app or on this page at least 7 days before taking effect. Material changes (new data collection, expanded third-party sharing, etc.) will be announced at least 30 days in advance.
